# Member 2 – Stages 01 to 03

### The Vanishing Trace | IE3132 – CTF Project

This folder contains my contributions to *The Vanishing Trace* Capture The Flag (CTF) project, focusing on three cybersecurity challenges.

- **Stage 01 – Steganography:** Hiding and extracting secret information from images.
- **Stage 02 – Web Security:** Demonstrating Insecure Direct Object Reference (IDOR) vulnerabilities using Flask.
- **Stage 03 – Cryptography:** Solving encrypted messages using cipher techniques and clues.

**Technologies:** Python, Flask, Steganography, Cryptography, Git and GitHub.

These challenges help participants develop practical cybersecurity, problem-solving, and security testing skills.
