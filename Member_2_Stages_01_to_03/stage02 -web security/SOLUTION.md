# Organizer reference — Stage 02

The toy demo returns record details by numeric ID without an authorization check. A guest can ask for a record belonging to another fictional user, demonstrating an insecure direct object reference (IDOR). `solve.py` shows a minimal safe request against loopback or the isolated coursework subnet.

**Do not represent this as the real Flask application** or a penetration test on a production service. Verify the genuine CTFd integration and target independently.
