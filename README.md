# Member 4 – Integration and Testing

## The Vanishing Trace | IE3132 – Penetration Testing

### Overview

This folder contains Member 4's contributions to *The Vanishing Trace*, a Capture The Flag (CTF) cybersecurity project. The main focus is on system integration, challenge testing, flag validation, security verification, and recovery procedures.

### Main Responsibilities

- **Integration Testing:** Verify that all six CTF challenges work correctly with the CTFd platform.
- **Flag Validation:** Test correct and incorrect flag submissions.
- **Functional Testing:** Check challenge accessibility, expected behavior, and solver functionality.
- **Security Testing:** Verify network isolation and challenge environment security.
- **Defect Management:** Identify issues, document fixes, and perform retesting.
- **Recovery Testing:** Check challenge reset procedures and system restoration.

### Technologies and Tools

- CTFd Platform
- Python
- Docker
- Kali Linux
- Git and GitHub
- VirtualBox
