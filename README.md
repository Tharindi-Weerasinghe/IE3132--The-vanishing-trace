## Member 2 – Stages 01 to 03

### Project: The Vanishing Trace
**Module:** IE3132 – Penetration Testing  
**Project Type:** Capture The Flag (CTF)

### My Contribution

As Member 2, I was responsible for developing and organizing the first three cybersecurity challenges in *The Vanishing Trace* CTF project. These challenges focus on steganography, web application security, and cryptography.

### Stage 01 – Hidden Photograph (Steganography)
- Designed a challenge involving hidden information inside an image.
- Used steganography concepts to demonstrate how secret information can be concealed and extracted.
- Prepared challenge files and supporting instructions.

### Stage 02 – Abandoned Website (Web Security)
- Developed a web security challenge based on Insecure Direct Object Reference (IDOR).
- Used Python Flask to demonstrate insecure access to web resources.
- Prepared challenge files to help participants understand access control vulnerabilities.

### Stage 03 – Encrypted Message (Cryptography)
- Prepared a cryptography challenge involving an encrypted message.
- Used cipher techniques and clues to guide participants through the decryption process.
- Organized the challenge source files and supporting documentation.

### Technologies and Tools

- Cryptography techniques
